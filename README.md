# Birthday website 🎀

## Personalize
Open `js/script.js`. Everything you need to change is in the `CONFIG` block at the top:
- `herName`: her name (shows in the title, nav, and letter)
- `treats`: the message and photos behind each clickable icon
- `letter`: your letter, one paragraph per line

## Add photos
Put your pictures in the `img/` folder using the file names listed in `CONFIG`
(for example `img/gift-1.jpg`). Names are case sensitive and should have no spaces.
Until a photo is added, the popup shows a pink placeholder telling you which file it's looking for.

## Upload to GitHub Pages
Same as before: upload everything so `index.html` sits at the root of the repo,
then check Settings → Pages → Deploy from branch → main → / (root).
